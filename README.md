# Fly Hero 🎸🪰

Муха-дрозофила играет в Guitar Hero. Играет симуляция её настоящего мозга: 14 664 нейрона из коннектома FlyWire,
LIF-модель Shiu et al. 2024.

## Как муха играет на гитаре

Ноты едут по грифу и **надвигаются** — для мухи это то же, что летящая мухобойка. Гитара на 4 лада, каждый лад —
отдельный нейронный канал:

| Лад | Вход (что видит или чувствует муха) | «Нажатие» |
|---|---|---|
| ◀ левый глаз | нота надвигается слева — LPLC2 | нейроны поворота вправо (DNa01/02) > 15 Гц |
| ▶ правый глаз | нота надвигается справа — LPLC2 | нейроны поворота влево > 15 Гц |
| 🍬 сахар | сладкая нота под лапкой — вкусовые рецепторы | хоботок MN9 > 25 Гц |
| ⚡ рок-прыжок | нота летит в оба глаза | giant fiber > 60 Гц без поворота |

Мозгу нужно время, чтобы разогнаться, поэтому стимул начинается заранее — это калибровка задержки, как в настоящем
Guitar Hero: ◀ 180 мс, ▶ 185 мс, 🍬 90 мс, ⚡ 155 мс. После калибровки муха попадает в ноты с точностью до пары
десятков миллисекунд.

| Песня | Стиль и форма |
|---|---|
| Smoke on the Vinegar — Deep Pupa | похоронный дум, си гармонический минор, 84 BPM: тема, брейкдаун, соло, второй куплет, бридж, соло-кульминация |
| Highway to Банан — AC/DNa | галоп, ре гармонический минор, 120 BPM: тема, брейкдаун, соло, второй куплет, бридж, второй брейкдаун, соло-кульминация |
| Smells Like Geosmin — Нервана | трэш, до-диез фригийский, 170 BPM: тема, брейкдаун, соло, второй куплет, второй брейкдаун, соло-кульминация |
| Livin' on a Pear — Bon Juicy | блэк, до-диез гармонический минор, 220 BPM: арпеджио, брейкдаун и быстрый соляк шестнадцатыми (15 нот в секунду) |

Точность мухи по песням печатает `npm run autoplay`.

## Музыка

Мелодии оригинальные и записаны нотами в `src/game/songs.ts` (`E4/2` — ми, две восьмых, `E4/0.5` — шестнадцатая); песня пишется в удобной тональности и опускается на `transpose` полутонов: в тональности, с опорой на
ноты аккорда на сильных долях (это проверяет тест) и с разрешениями в конце фраз. Аранжировка собирается из гармонии:
ритм-гитара с дисторшном в очень низком строе (тоника G1–F#2; пауэр-аккорды открытые и глушёные ладонью, в брейкдаунах риффы с малой секундой и тритоном — под быстрым соло хроматики нет, чтобы не спорить с мелодией), погребальный колокол, бас в унисон октавой ниже, тёмный пэд, барабанный грув под стиль (дум, галоп, трэш, бласт, брейкдаун с бочкой в унисон с гитарой) в шестнадцатых, тарелки и сбивки на томах.

Соло строятся из мотивов: короткая фраза повторяется и проводится секвенцией по аккордам, движение в основном
поступенное, фразы разрешаются в тонику. Вторая гитара играет в гармонии, как у Iron Maiden: ближайшую ноту аккорда
на терцию–кварту ниже мелодии, каждая гитара — через свой перегруз, чтобы не было грязных разностных тонов.

Мелодия звучит всегда, попала муха или нет: промахи видны в очках, комбо и надписях, но не рвут музыку. Если рок-метр
падает до нуля, зал свистит, а песня всё равно доигрывает до конца.

Ноты для мухи выводятся из мелодии, как в Guitar Hero: мелодия идёт вверх — лад сдвигается вправо. Ноты, которые мозгу
не успеть (слишком близко друг к другу), играет «ритм-гитарист», поэтому мелодия не рвётся.

Звук синтезируется на Web Audio (`src/game/audio.ts`): гитара с мягким перегрузом, «подтяжкой» и вибрато, дилей в темп
песни, ревербератор, компрессор и лимитер. Всё планируется по часам AudioContext, а гитара мухи встаёт ровно в долю,
даже если нажатие было на пару десятков миллисекунд раньше.

## Режимы

- **Соло.** Муха играет, вы смотрите и можете кидать из зала 🍬 сахарок (лишний хоботок) или 🩴 тапок
  (рефлекс бегства) — оба сбивают комбо.
- **Дуэль.** Вы играете ту же песню на клавишах **A S D F** (или 1 2 3 4) против мухи. Спойлер: муха обычно выигрывает.
- **Послушать трек.** Песня сыграна идеально, без мухи — чтобы оценить музыку.

## Развёртывание с нуля

Нужны Node.js ≥ 22 (в WSL — Linux-версия, например через `nvm install --lts`) и [uv](https://docs.astral.sh/uv/)
для подготовки данных мозга. Подробности установки — в README соседнего проекта `fly-plays`, шаги те же.

```bash
cd fly-hero
npm ci                                   # node_modules
cd pipeline && uv run fetch.py && uv run build.py && cd ..   # данные мозга → public/data
npm test                                 # 9 тестов, включая гармонию мелодий и «мозг допевает песню» (~30 с)
npm run dev                              # http://localhost:5300
```

Данные можно не собирать, а скопировать из `fly-game` или `fly-plays`: `cp -r ../fly-plays/public/data public/`.

```bash
npm run autoplay              # муха играет все песни без браузера
npm run autoplay -- highway   # одну песню
```

## Устройство

| Файл | Что делает |
|---|---|
| `src/game/hero.ts` | логика: ноты, окна попадания, каналы нажатий, стимулы с упреждением |
| `src/game/songs.ts` | песни нотами, гармония, грувы; вывод нот для мухи и аранжировки |
| `src/game/audio.ts` | синтезатор: барабаны с томами, бас, ритм-гитара с дисторшном, пэд, соло-гитара, дилей, реверб, компрессор и лимитер |
| `src/game/render-highway.ts`, `render-stage.ts` | гриф и сцена |
| `src/main.ts` | меню, дуэль, саботаж, итоги; время игры идёт по времени симуляции мозга |
| `src/sim/*`, `src/ui/brain-view.ts` | симуляция мозга в Web Worker — из fly-game |

Источники: Dorkenwald et al. 2024 и Schlegel et al. 2024 (FlyWire, CC-BY), Shiu et al. 2024 (модель мозга).
